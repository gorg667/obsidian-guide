    The Mastery Roadmap¶

    Reading about a system is not the same as living in one. This chapter sequences everything in the guide into a schedule you can actually follow — a first 30 days that establishes the habit, days 30–90 that build the systems, a year that brings every life domain online, and beyond — with weekly exercises, a self-assessment, and a maturity model so you know where you are. The pacing is deliberate: too fast and you build a cathedral nobody visits; too slow and the old tools creep back.

    Principles of the roadmap¶

    1. Use before build. Every phase starts with using what exists for two weeks before adding.
    2. One domain at a time. Bring life areas into the vault one per month, not all at once.
    3. Habit first, system second. The daily note and the weekly review are the habits; everything else is optional until those hold.
    4. Measure by retrieval, not by notes written. The test of the vault is how often it answers a question you actually had.
    5. Ship the skeleton on day one; freeze it for a year. Change what is inside it freely.

    Phase 0 — Day 0 (2 hours): foundation¶

    • Install; update installer; create the vault on local disk; choose sync (Chapter 26) and set it up.
    • Settings audit (Chapter 2 checklist).
    • Create the folder skeleton (Chapter 8) — delete folders for domains you will not touch this quarter.
    • Install Tier 1 plugins only: Templater, Tasks, Periodic Notes, Calendar, Omnisearch, Linter, Style Settings, Homepage (Chapter 14).
    • Paste the core templates (Chapter 36): daily, weekly, project, area, person, source, note, meeting. Set folder templates.
    • Create 00 Home.md, Areas/ notes (5–8 areas, one line each), one project note per active project, Inbox.base, Projects.base.
    • Write Meta/Vault Guide.md (half a page: folders, types, rules) and Meta/Schema.md (the properties you are using).
    • Write today's daily note. Stop.

    Phase 1 — Days 1–30: the habit¶

    Goal: open Obsidian every day; the daily note and the weekly review become automatic.

    Week Focus Exercises
    1 Daily note Every day: three intentions, a few log lines, evening three prompts. Link every person and project you mention. Capture every task in the daily note.
    2 Weekly review #1; linking Sunday: the review checklist, 30 minutes, even if it feels pointless. Open two people notes and read their backlinks. Convert 10 unlinked mentions.
    3 Search and navigation Learn ten hotkeys (Chapter 2). Bookmark three searches. Use the quick switcher for everything; do not click the file tree for a week. Try Omnisearch for a half-remembered phrase.
    4 Processing Daily five-minute inbox processing (Chapter 16). Write your first three idea notes from things you read this month (Chapter 17). Weekly review #4: notice what the checklist caught.

    End-of-phase check: 25+ daily notes exist; you have done four weekly reviews; you can create a typed note in under 10 seconds; the old note-taking app has not been opened in two weeks. If not, stay in Phase 1 another two weeks — nothing later works without this.

    Phase 2 — Days 31–90: the systems¶

    Goal: action management, knowledge pipeline, and the first two life domains run in the vault.

    Month Build Use
    2 Action system (Chapters 13, 16): Tasks dashboards (Today, Week, Portfolio, Waiting), Routines.md, goals for the quarter, the Action Dashboard note. Add Dataview, QuickAdd, Meta Bind. Plan the week from the Focus section; schedule with ⏳; cap active projects at 5; log progress in project notes.
    2 Knowledge pipeline (Chapter 17): tpl-book, Web Clipper with two templates, Reading Base, Ideas Base. Finish one book through the pipeline: source note → summary → three idea notes → linked into a MOC.
    3 Domain 1 — Journaling depth (Chapter 15): weekly/monthly templates complete, mood/energy/sleep properties, Meta Bind sliders on mobile, first monthly review. Read back the first month: the on-this-day widget, the Daily Base averages.
    3 Domain 2 — People (Chapter 23): person notes for the 30 people who matter, contact_every, People Base. Weekly: message one contact-due person. Open a person note before every meeting.
    3 Mobile (Chapter 27): toolbar, Share Sheet locations, log-line capture, light daily template. Capture from the phone daily for a week without opening a laptop.

    End-of-phase check: the Today view is where your day starts; every active project has a next action; you have written 15+ idea notes and one MOC; your phone captures land in the vault; you have done one monthly review. Plugin count ≤ 15.

    Phase 3 — Months 4–12: everything in life¶

    One domain per month, in the order that matters to you. Suggested sequence with what "done" looks like:

    Month Domain Done when
    4 Work (Chapter 19) Meeting template in daily use; decision log started; brag document has 10 entries; work dashboard.
    5 Health (Chapter 20) Workouts logged for a month; health events for the year backfilled from memory/records; medications/labs/emergency notes exist; habits heatmap.
    6 Finance (Chapter 21) Accounts registry, Subscriptions Base (and you cancelled something), first net-worth snapshot, tax note for the year, one financial decision logged.
    7 Home & admin (Chapter 22) Home hub, appliances with service dates, documents with expiry, Emergency & Legacy note exported, routines as 🔁 tasks.
    8 Mind (Chapter 25) Values written, five principles, three decisions with review dates, first belief notes, prompts rotation live.
    9 Creativity/media (Chapter 24) Ideas pipeline, one writing project drafted from idea notes, media log running.
    10 Research/learning depth (Chapters 17–18) Spaced repetition deck in daily use; if academic: Zotero pipeline and Pandoc export working.
    11 Automation (Chapter 29) CLI installed; three scripts (morning, capture, nightly CSV export); Web Clipper templates for your top sites; one calendar→meeting automation.
    12 Customization, AI, publishing (Chapters 28, 30, 31) Ten snippets you use; Smart Connections or Copilot configured with privacy tiers; if you want to publish: a garden of 20 evergreen notes live.

    Throughout: monthly review (Chapter 15), quarterly portfolio review (Chapter 16), quarterly plugin audit (Chapter 32).

    End-of-year check: the annual review (Chapter 15/25) is written from the vault — stats from Bases, decisions reread, monthly notes skimmed. If that review takes under a day and teaches you something, the system works.

    Year 2 and beyond: depth and pruning¶

    • Prune: the quarterly audits remove plugins, templates, properties and dashboards you do not use. A mature vault is simpler than a one-year-old vault.
    • Deepen: idea notes mature to evergreen; MOCs get curated; decisions get graded; beliefs get updated; the reading pipeline compounds.
    • Automate the boring: anything you type more than weekly in the same shape becomes a template, a QuickAdd, or a script.
    • Teach: write your own vault guide as if for someone else (a Publish/Quartz garden of your methods is a fine first public output).
    • Re-examine yearly: the skeleton, the schema, the sync/backup/security checklist, the Emergency & Legacy export, the vault guide.

    Weekly exercises (rotate; 15 minutes each)¶

    1. Open the local graph (depth 2) on a random idea note; add one missing link.
    2. Pick the oldest seedling; develop it or delete it.
    3. Read three random daily notes from a year ago.
    4. Convert one hand-maintained list into a Base.
    5. Write one decision note for something you decided this week without thinking.
    6. Find one unlinked-mentions hub note and link all mentions.
    7. Review the Tags view; merge or delete two tags.
    8. Try one hotkey you never use; keep it or unbind it.
    9. Read a plugin's release notes; change one setting deliberately.
    10. Explain one thing you learned this week to someone; link the note to the conversation.

    Self-assessment¶

    Score each 0–3 (never / sometimes / usually / always). Under 20: Phase 1. 20–35: Phase 2. 35–50: Phase 3. 50+: depth.

    # Statement
    1 I open my daily note every day.
    2 I do a weekly review, and it changes what I do the next week.
    3 Every task I have lives in the vault or a calendar, not my head.
    4 Every active project has a written outcome and a next action.
    5 I can find any note I remember writing in under 30 seconds.
    6 People I care about have notes, and I read them before we talk.
    7 Reading produces idea notes in my own words.
    8 Lists of things (books, projects, subscriptions) are Bases, not hand-maintained.
    9 I capture from my phone without friction.
    10 My vault is backed up in three places and I have tested a restore.
    11 I can name what every installed plugin does for me.
    12 I have written down my values and at least three decisions with review dates.
    13 Health, money and home records are findable in the vault.
    14 I have read back my journal (on-this-day, monthly review) this month.
    15 I have automated at least one recurring capture.
    16 I know what I would never publish and the tooling enforces it.
    17 The annual review can be written from the vault's data.
    18 My vault guide is current.

    Maturity model¶

    Level Name Description Typical vault
    0 Notebook Notes as files; folders; some links. Hundreds of notes; no properties; no reviews.
    1 Journal Daily note habit; links to people/projects; weekly review. Daily notes for months; backlinks used; 5–10 plugins.
    2 System Typed notes; templates; Tasks dashboards; Bases; two or three life domains. Schema exists; Home dashboard; 10–20 plugins; monthly reviews.
    3 Life OS All domains; periodic-notes ladder; decision journal; mobile capture; automation; backups tested. Thousands of notes; Bases everywhere; scripts; quarterly audits.
    4 Compounding Idea notes mature; decisions graded; beliefs updated; outputs published; the vault answers questions you did not know you had. Years of data; simpler than at level 3; teaches others.

    Most dedicated users reach level 2 in three months and level 3 in a year. Level 4 is a practice, not a destination.

    Anti-roadmap (what not to do)¶

    • Spend the first weekend installing 40 plugins and building 12 dashboards.
    • Import 10,000 notes on day one and try to organize them.
    • Copy a YouTuber's vault.
    • Change the folder structure monthly.
    • Skip the weekly review because the system "isn't ready yet".
    • Wait to write until the schema is perfect.

    Key takeaways¶

    • Day 0: skeleton, Tier 1 plugins, core templates, Home, first daily note — two hours, then stop.
    • Days 1–30: daily note and weekly review until automatic; nothing else matters yet.
    • Days 31–90: action system, knowledge pipeline, journaling depth, people, mobile.
    • Months 4–12: one life domain per month, with monthly/quarterly reviews and plugin audits.
    • Year 2+: prune, deepen, automate, teach, re-examine yearly. Use the self-assessment and maturity model to know where you are.
